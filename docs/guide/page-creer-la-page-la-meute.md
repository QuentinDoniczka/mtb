# Créer la page « La meute »

**Quand** : une seule fois, avant de montrer vos chiens aux visiteurs.
**Temps** : 5 minutes. **Rattrapable** : oui. Une page se modifie, se dépublie et se met à la corbeille
sans rien perdre.

**Cette page n'existe pas encore sur votre site : vous devez la créer.** Tant qu'elle n'existe pas, le
lien **La meute** que le site propose sur ses pages d'erreur ne mène nulle part.

Une fois créée, elle se remplit toute seule à partir de vos fiches de chien. **Vous n'y écrirez plus
jamais un nom ni ne poserez plus jamais une photo.**

---

## Les étapes

1. Dans le menu de gauche, cliquez sur **Pages**, puis sur **Toutes les pages**.
2. En haut de l'écran, à côté du titre **Pages**, cliquez sur le bouton **Ajouter une page**.
3. Dans le champ du titre, tapez exactement **La meute**. L'adresse de la page se compose toute seule à
   partir de ce titre.
4. Placez le curseur sous le titre, puis cliquez sur le bouton **+**, en haut à gauche de l'écran.
5. Dans la liste qui s'ouvre, **Mont Brabant** est la première rubrique : cliquez sur
   **Grille de chiens**.
6. **Ne touchez à aucun réglage.** Le bon réglage est déjà choisi.
7. Cliquez sur **Publier**, en haut à droite, puis confirmez.
8. Ouvrez la page sur le site : vos chiens y sont, groupés par statut.

**Tant que vous n'avez pas publié, rien n'est en ligne.** Vous pouvez quitter la page sans enregistrer.

Le composant est décrit en entier dans « Afficher les chiens dans une page » : ses réglages, ce qu'une
vignette montre, et comment l'enlever.

---

## Ce qui se met à jour tout seul

- **Les chiens.** Une fiche publiée avec un **Statut** apparaît sur cette page, sans que vous la
  rouvriez.
- **Les groupes et leurs titres** — **Reproducteurs**, **En cours de confirmation**, **Retraités**,
  **Disparus** — s'écrivent tout seuls, toujours dans cet ordre. Un groupe sans chien n'apparaît pas.
- **Les photos, les noms et les liens** vers les fiches.

**Vous ne revenez jamais sur cette page.** Une naissance, une retraite, une nouvelle photo : tout se
fait sur la fiche du chien.

---

## Un chien qui n'apparaît pas : neuf fois sur dix, c'est le **Statut**

**Un chien sans Statut n'apparaît dans aucun groupe.** Il n'est pas dans une catégorie « autres », il
n'est nulle part — et la page ne le signale pas.

**Comment le remarquer** : comptez les chiens sur la page, et comparez avec **Chiens** →
**Tous les chiens**. Un écart, c'est un statut manquant.

**Comment le corriger** :

1. Dans le menu de gauche, cliquez sur **Chiens**, puis sur **Tous les chiens**.
2. Cliquez sur le nom du chien.
3. Dans l'encadré **Identité**, champ **Statut**, choisissez **Reproducteur**,
   **En cours de confirmation**, **Retraité** ou **Disparu**. Sur une femelle, le libellé s'accorde
   tout seul : **Reproductrice**, **Retraitée**, **Disparue**.
4. Cliquez sur **Mettre à jour**. Le chien apparaît aussitôt sur **La meute**.

**Le site vous prévient** quand vous enregistrez une fiche sans statut : « Ce chien est enregistré sans
statut : il n'apparaîtra pas sur la page « La meute ». Vous pouvez renseigner le champ Statut quand
vous le souhaitez. » **Ce message ne s'affiche qu'au moment où vous enregistrez** : les fiches qui ont
été mises en place pour vous ne l'ont jamais montré. **Vérifiez-les une par une la première fois.**

Deux autres raisons, plus rares : la fiche est encore **en brouillon**, ou elle est **protégée par un
mot de passe** — une fiche protégée n'apparaît dans aucune grille, et c'est voulu.

---

## Ce qu'il vaut mieux ne pas faire

- **Ne posez pas les photos et les noms à la main** dans cette page. Vous auriez à y revenir à chaque
  naissance et à chaque retraite — c'est exactement le travail que ce site supprime.
- **N'écrivez pas de titre au-dessus de la grille** : les titres de groupes sont déjà écrits.
- **Ne créez pas deux pages « La meute ».** Si vous avez un doute, cherchez « meute » dans
  **Toutes les pages** avant d'en ajouter une.

---

## En cas de doute

**C'est normal, vous n'avez rien à faire :**

- Un groupe manque : aucun chien publié ne porte ce statut. Il apparaîtra le jour venu.
- Une vignette n'a pas de photo : sa place est gardée, à la même taille que les autres. Ajoutez une
  **Photo principale** à la fiche du chien.
- Pendant que vous modifiez la page, la grille est plus étroite que sur le site et montre moins de
  colonnes. C'est la fenêtre de travail qui est étroite, pas la page. **C'est le site qui compte.**

**Ce n'est pas normal, signalez-le :**

- Un chien publié, avec un statut, qui n'apparaît pas après **Mettre à jour**.
- Le bouton **+** qui ne propose aucune rubrique **Mont Brabant**.

**Si quelque chose vous inquiète** : ne supprimez rien, notez le titre de la page et l'heure, et
appelez-nous. Une page en cours de modification n'a jamais cassé un site.
