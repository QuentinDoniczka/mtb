# Le guide de votre site

**Tout ce qui change dans la vie de l'élevage — une portée, un chien, une photo, un résultat, un
texte — se modifie depuis l'administration du site, en remplissant des champs nommés en français.**
Vous n'ouvrez jamais un fichier, vous ne recopiez jamais une page.

Ce guide n'est pas fait pour être lu d'un bout à l'autre. Chaque page répond à **un besoin, et un
seul** : trouvez le vôtre dans les tableaux ci-dessous, ouvrez la page, faites ce qu'elle décrit,
refermez.

## Quand quelque chose vous inquiète

**[En cas de doute](en-cas-de-doute.md)** : ce que vous pouvez faire sans rien risquer, ce qui n'est
pas entre vos mains et ne peut donc pas être abîmé, les trois choses à ne jamais faire, et quoi noter
avant de nous appeler.

Ouvrez-la aussi **avant** de toucher à quelque chose dont vous n'êtes pas sûre. C'est souvent la
lecture la plus courte de la soirée.
