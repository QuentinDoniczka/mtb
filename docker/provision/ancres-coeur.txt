# Registre des ancres du cœur WordPress — issue #57 (T114), contrat docs/contracts/issue-57.md
#
# CE QUE C'EST. Une ligne par fichier du cœur WordPress cité AVEC UN NUMÉRO DE LIGNE, où que ce soit,
# sous wp-content/plugins/mtb-core/, wp-content/themes/mtb/, docs/contracts/ ou docs/ETAT.md. Le cœur
# n'est pas versionné dans ce dépôt : ce registre est ce qui permet au témoin
# docker/provision/temoin-ancres.sh de dire qu'un fichier cité a changé depuis son relevé.
#
# FORMAT, une ligne par fichier, champs séparés par une ou plusieurs espaces :
#   <version relevée> <AAAA-MM-JJ> <md5 en minuscules> <chemin relatif à la racine du cœur>
# Lignes « # » et lignes vides ignorées. Tri par chemin (LC_ALL=C sort -k4). Chemin sans « .. », sans
# espace, présent une seule fois. Une fin de ligne CRLF (checkout Windows) est tolérée.
#
# RÈGLES, GELÉES PAR LE CONTRAT #57 §1 :
#   1. AJOUT. Toute nouvelle citation d'une ligne du cœur ajoute la ligne de ce fichier ici, DANS LE
#      MÊME COMMIT. Empreinte relevée dans le conteneur wpcli :
#        docker compose exec -T wpcli sh -c 'cd /var/www/html && md5sum <chemin>'
#   2. MISE À JOUR APRÈS ALERTE. Une empreinte ne change qu'APRÈS RELECTURE DE TOUTES LES CITATIONS du
#      fichier, y compris les « même fichier, l. N » et les « :N » nus. Version, date et empreinte
#      changent ENSEMBLE, sur la même ligne. Une citation fausse dans un contrat gelé se corrige par
#      acte daté, jamais par réécriture.
#   3. AVERTISSEMENT. Sur AVERTISSEMENT (fichier identique, autre version installée), on re-date la
#      version et la date, JAMAIS l'empreinte.
#   4. RETRAIT. Une ligne ne se retire que lorsque la recherche ne rend plus aucune citation du fichier :
#        git grep -n -F -e '<nom du fichier>' -- wp-content/plugins/mtb-core wp-content/themes/mtb docs/contracts docs/ETAT.md
#   5. PRÉFÉRER citer un nom de crochet ou de fonction plutôt qu'un numéro de ligne : un nom ne se
#      périme pas au premier ajout de ligne au-dessus de lui.
#
# EXCLUSIONS. wp-config.php (généré par l'image, pas un fichier du cœur) ; tout fichier du dépôt ; les
# outils hors de la racine du cœur (par exemple le binaire WP-CLI /usr/local/bin/wp, cité par le
# contrat #30). Un nom nu que le contexte de sa citation ne tranche pas y figure pour TOUS ses candidats.
#
